# مدينة الباحث

لعبة تعليمية ثلاثية الأبعاد من المكعبات تغطي **مذكرة مناهج البحث الاقتصادي** (برنامج ماجستير الاقتصاد الإسلامي، الجامعة الإسلامية بالمدينة المنورة، د. عبد السلام أحمد سومر) من أولها إلى آخرها (٩٩ صفحة).

- ستة أحياء: أسس البحث العلمي، أنواع البحوث ومناهجها، خطة البحث، مصادر المعرفة والاقتصاد الإسلامي، جمع البيانات والعينات، التحليل والتفسير والتوثيق.
- ٥٨ درسًا، بجانب كل فكرة رقم صفحتها في المذكرة، وما زيد للتوضيح موسوم «إضافة توضيحية».
- محاكيات: مختبر البحث المختلط، مرشد اختيار المنهج، تجربة الحد الأدنى للأجور (تجريبية/ضابطة)، مشرّح العنوان، المستقل والتابع، ميزان التعارض، ألفا كرونباخ، سحب العينات بأربع طرق، حجم العينة، المقاييس الإحصائية، الارتباط والانحدار، فاحص الاقتباس، ترتيب المراجع، وألعاب ترتيب الخطوات.
- سؤال سريع لكل درس، و٥٢ سؤالًا في اختبارات الأحياء، وست مجموعات في «ميزان التصنيف»، وجداول المقارنات الكبرى، وشهادة إتمام.

## التشغيل
```
python3 -m http.server
```
ثم افتح `http://localhost:8000`.

## الملفات
- `index.html`: الواجهة والتنسيق.
- `js/content.js`: محتوى المذكرة (الدروس والأسئلة والمقارنات وبطاقات التصنيف).
- `js/game.js`: محرك العالم والتفاعل والمحاكيات.
