# مدينة الأسواق المالية

لعبة تعليمية ثلاثية الأبعاد من المكعبات تشرح مقرر **الأسواق المالية (٥٢٠٥ قصد)** من أوله إلى آخره.

## هيكل المستودع

| المجلد | ما فيه |
|---|---|
| `files/` | الملفات المرفقة: المذكرة والملخص |
| `sites/` | المواقع والصفحات: `sites/cards/` موقع البطاقات |
| `games/` | الألعاب التعليمية: `madinat-alaswaq/` (مدينة الأسواق المالية) |
| `index.html` | بوابة المقرر: روابط المذكرة والملخص والبطاقات والألعاب |

> ⚠️ الملخصات والبطاقات والألعاب أُعدّت عبر نماذج الذكاء الاصطناعي ولم تتقدّم مراجعتها ولا تدقيقها؛ والتحقق منها مطلوب من الطالب مع مطابقتها بالمذكرة المعتمدة.

- ستة أحياء، لكل فصل حيّ بلونه، وفيه ألواح الدروس (٤٠ درسًا) ومكعب اختبار الفصل.
- محاكيات تفاعلية: التطهير، وحق الأولوية، وأذون الخزانة، والشراء بالهامش، والبيع على المكشوف، وخيار الشراء، والمؤشر، ولعبة سجل الأوامر.
- قاعة الخلاصة في الوسط: جدول خلاصة الأحكام، ولعبة «ميزان الأحكام»، وشهادة الإتمام.
- يعمل على الحاسوب (لوحة المفاتيح والفأرة) وعلى الجوال (عصا تحكم وأزرار).

## حزمة المذاكرة
- `files/مذكرة-الأسواق-المالية.pdf`: المذكرة الأصلية للمقرر (30 صفحة)، إعداد الطلاب زيد العوفي وعبدالرحمن الأحمدي وعبدالله الذبياني، مقدمة إلى د. فارس العلوني (1448هـ).
- `sites/cards/`: موقع بطاقات المذاكرة (100 بطاقة في 4 مستويات متدرجة، بزر «تم» ويُحفظ التقدم في المتصفح). المستويات كلها مفتوحة، وزر «🔗 انسخ رابط تقدّمك» يحفظ ما أنجزته وموضعك في الرابط نفسه فيعيدك إليه ولو مُسح حفظ المتصفح.
- `files/mulakhas-aswaq-maliyaah.pdf`: ملخص المقرر في 10 صفحات، فيه جداول وخرائط ذهنية وخلاصة الأحكام.

## التشغيل
افتح `games/madinat-alaswaq/index.html` عبر أي خادم ملفات ثابت، مثل:

```
python3 -m http.server
```

ثم زر `http://localhost:8000/games/madinat-alaswaq/`.

## الملفات
- `games/madinat-alaswaq/index.html`: الواجهة والتنسيق.
- `games/madinat-alaswaq/js/content.js`: محتوى المقرر (الدروس والأسئلة وخلاصة الأحكام).
- `games/madinat-alaswaq/js/game.js`: محرك العالم والتفاعل والمحاكيات.
